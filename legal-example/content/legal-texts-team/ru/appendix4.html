Настоящее Приложение устанавливает временные критерии индивидуального рейтинга, применяемые для определения соответствующего INDIVIDUAL LEVEL участников команды в системе ACE BATTLE RUN RATING.

2. ПРАВИЛА ПРИМЕНЕНИЯ ТАБЛИЦЫ

  1. INDIVIDUAL LEVEL является числовым показателем уровня участника в системе ACE BATTLE RUN RATING.

  2. Для целей настоящего Приложения применяются следующие категории участников:

    • RUNNER — участник, выступающий в соответствующей роли RUNNER;
    • ACE — участник, выступающий в роли ACE;
    • JOKER — участник, выступающий в роли JOKER.

  3. В зависимости от пола участника и его роли в командном забеге применяется соответствующая колонка таблицы.

  4. Для мужской категории применяются критерии:

    • Мужчины — RUNNERS;
    • Мужчины — ACE & JOKER.

  5. Для женской категории применяются критерии:

    • Женщины — RUNNERS;
    • Женщины — ACE & JOKER.

  6. Для смешанной команды применяются критерии:

    • Смешанная команда — RUNNERS;
    • Смешанная команда — ACE & JOKER.

  7. Полученный участником официальный результат используется для определения его индивидуального уровня в соответствии с настоящей таблицей.

  8. Индивидуальный уровень участника может использоваться для определения состава команды, командного рейтинга, распределения команд по уровням и дивизионам, а также для допуска к последующим соревнованиям системы ACE BATTLE RUN, если это предусмотрено соответствующими правилами.

  9. Правила определения итогового индивидуального рейтинга, в том числе правила учёта лучшего результата участника, применяются в соответствии с § 13 Регламента и соответствующими правилами ACE BATTLE RUN RATING.

  10. При наличии нескольких официальных результатов одного участника применяются правила определения лучшего официального результата, установленные основным Регламентом и соответствующими правилами рейтинговой системы.

  11. В случае изменения правил ACE BATTLE RUN RATING настоящая таблица может быть обновлена в порядке, установленном Регламентом.

3. ИСПОЛЬЗОВАНИЕ ИНДИВИДУАЛЬНЫХ УРОВНЕЙ В КОМАНДНОМ РЕЙТИНГЕ

  1. Командный рейтинговый забег предназначен для определения результата команды и её рейтингового уровня.

  2. Каждый участник получает индивидуальный результат и позицию в соответствующей классификации.

  3. Индивидуальный результат участника может служить основанием для присвоения ему статуса TEAM RUNNER в системе ACE BATTLE RUN RATING.

  4. Индивидуальные уровни участников используются в рамках установленных правил для формирования и распределения команд по соответствующим уровням и дивизионам.

  5. Индивидуальная классификация ведётся отдельно среди мужчин и женщин.

  6. Командная классификация ведётся по следующим категориям:

    1. мужские команды;
    2. женские команды;
    3. смешанные команды.

  7. Конкретные требования к составу команды, соответствию уровней участников и условиям допуска к последующим лигам или соревнованиям могут устанавливаться отдельными документами ACE BATTLE RUN RATING.

4. СТАТУС ПРИЛОЖЕНИЯ

  1. Настоящее Приложение № 4 является неотъемлемой частью Публичного регламента национальных рейтинговых соревнований ACE BATTLE RUN – TEAM MILE POLAND.

  2. Настоящее Приложение применяется совместно с § 8 «Командный формат и рейтинг» и с § 13. “Индивидуальный рейтинг” основного Регламента.

  3. В случае противоречия между настоящим Приложением и императивными нормами действующего законодательства применяются нормы законодательства.

  4. В случае противоречия между настоящим Приложением и основным Регламентом в части, регулирующей конкретные соревнования, применяются положения основного Регламента, если иное прямо не установлено соответствующими правилами ACE BATTLE RUN RATING.

  5. Актуальная редакция настоящего Приложения публикуется Организатором в официальном информационном и регистрационном ресурсе poland.acebattle.run.
