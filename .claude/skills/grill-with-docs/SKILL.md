Run a `/grilling` session, using the `/domain-modeling` skill.

When the plan is a Teams Mile feature, walk the cross-cutting checklist
(`docs/agents/cross-cutting-checklist.md` at the repo root) as part of the
interview — trilingual i18n, auth gating, flow states, SSG/migrations, the
modal+fallback pattern, reuse targets, emails, leanness. Decisions land in the
conversation; `/to-prd` will freeze them afterwards.
