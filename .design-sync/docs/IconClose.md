# IconClose

Close (a cross), for dismissing dialogs and banners.

An inline SVG that inherits `currentColor` and accepts any SVG prop,
so size and colour come from the parent or from utilities.

## Use

```tsx
<IconClose className="h-4 w-4" />
<Button intent="ghost"><IconClose className="h-4 w-4" /> Label</Button>
```
