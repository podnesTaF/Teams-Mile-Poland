# IconPerson

A single runner — the solo entry path.

An inline SVG that inherits `currentColor` and accepts any SVG prop,
so size and colour come from the parent or from utilities.

## Use

```tsx
<IconPerson className="h-4 w-4" />
<Button intent="ghost"><IconPerson className="h-4 w-4" /> Label</Button>
```
