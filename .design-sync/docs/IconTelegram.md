# IconTelegram

Telegram logo, for contact links.

An inline SVG that inherits `currentColor` and accepts any SVG prop,
so size and colour come from the parent or from utilities.

## Use

```tsx
<IconTelegram className="h-4 w-4" />
<Button intent="ghost"><IconTelegram className="h-4 w-4" /> Label</Button>
```
