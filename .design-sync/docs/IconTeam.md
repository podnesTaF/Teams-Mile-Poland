# IconTeam

A group of runners — the team entry path.

An inline SVG that inherits `currentColor` and accepts any SVG prop,
so size and colour come from the parent or from utilities.

## Use

```tsx
<IconTeam className="h-4 w-4" />
<Button intent="ghost"><IconTeam className="h-4 w-4" /> Label</Button>
```
