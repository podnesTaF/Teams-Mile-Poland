# IconBack

Back chevron, for returning a step in a flow.

An inline SVG that inherits `currentColor` and accepts any SVG prop,
so size and colour come from the parent or from utilities.

## Use

```tsx
<IconBack className="h-4 w-4" />
<Button intent="ghost"><IconBack className="h-4 w-4" /> Label</Button>
```
